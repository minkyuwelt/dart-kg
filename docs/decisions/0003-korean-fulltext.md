# 0003. 한국어 전문검색: Neo4j `cjk` 분석기 + 구절 검색 + 영문·숫자 경계 공백

- 날짜: 2026-11-23
- 상태: 채택 (Phase 3에서 실제 공시 원문으로 다시 확인)
- 관련: 0001(기술 스택)의 "확인이 필요한 것" 중 "Neo4j 전문검색의 한국어 처리"

## 배경

0001에서 그래프·벡터·전문검색을 Neo4j 하나에 모으기로 했다(구조 Y). 이 구조가 성립하려면 Neo4j 전문검색이 한국어 공시 문장에서 쓸 만해야 한다. Phase 3에서 알게 되면 되돌리기 비싸므로 미리 작은 실험을 했다.

## 실험

- 환경: `neo4j:2026.06-community` (Neo4j 2026.06.0), 실험용 컨테이너를 127.0.0.1:17474/17687에 띄우고 끝난 뒤 삭제
- 코드: `notebooks/neo4j_korean_fulltext_poc.py`, 결과: `notebooks/neo4j_korean_fulltext_poc_result.txt`
- 문서 14개: 공시 제목(list.json의 report_nm 형식) 6개 + 사업보고서 본문 같은 문장 8개. 영문·숫자가 한글에 붙은 문장(`KB국민은행`, `SK하이닉스`, `신한DS`, `2025년`) 포함
- 검색어 15개, 검색어마다 사람이 정답 문서를 정해 두고 재현율(정답 중 찾은 비율)과 정밀도(찾은 것 중 정답 비율)를 잼

## 확인한 사실

1. **Neo4j에는 한국어 전용 분석기가 없다.** 사용 가능한 분석기 45개 중 한국어에 쓸 수 있는 것은 `standard` 계열(공백·문장부호로 자름)과 `cjk`(두 글자씩 겹쳐 자름, bigram)뿐이다. Lucene의 한국어 형태소 분석기(nori)는 들어 있지 않다.
2. **`cjk` 분석기는 영문·숫자가 한글에 붙은 덩어리를 쪼개지 않는다.** `KB금융지주이며`, `SK하이닉스와`가 토큰 하나가 되어 `금융지주`, `하이닉스`로 찾을 수 없다. 이 프로젝트는 회사명에 영문이 붙은 경우가 많아서(`KB국민은행`, `KB증권`, `신한DS`) 그냥 넘길 수 없다.

## 결과 (검색어 15개, 정답 26개)

| 방법 | 재현율 | 정밀도 | 문제 |
|---|---|---|---|
| `standard` 그대로 | 15% | 100% | 붙여 쓴 공시 제목(`최대주주등소유주식변동신고서`)을 통째로 단어 하나로 봄 |
| `standard` 앞부분 일치(`최대주주*`) | 54% | 100% | 조사는 처리되지만 복합어 중간(`소유주식`의 `주식`)은 못 찾음 |
| `cjk` 그대로 | 85% | 63% | 조각 하나만 맞아도 찾음 (`최대주주` → `주주총회`도 나옴) |
| `cjk` 구절 검색(`"최대주주"`) | 85% | 100% | 영문·숫자가 붙은 문장을 모두 놓침 |
| **`cjk` 구절 검색 + 영문·숫자 경계 공백** | **100%** | **100%** | 없음 (이 실험 범위에서) |

## 결정

전문검색은 다음 세 가지를 함께 쓴다.

1. **인덱스 분석기:** `cjk`
2. **검색어:** 공백으로 나눈 낱말마다 큰따옴표로 묶은 구절 검색, 낱말끼리는 AND (`"대표이사" AND "변경"`)
3. **전처리:** 저장할 때와 검색할 때 **모두** 영문·숫자와 한글 사이에 공백을 넣는다 (`KB국민은행` → `KB 국민은행`, `2025년` → `2025 년`)

전처리 함수는 Phase 3에서 `src/` 아래 공통 함수로 옮기고, 색인과 검색이 같은 함수를 쓰게 한다. 둘 중 한쪽만 바꾸면 검색이 조용히 실패한다.

**0001의 구조 Y(Neo4j 하나에 그래프·벡터·전문검색)는 유지한다.**

## 이 실험의 한계 (Phase 3에서 다시 확인할 것)

- **표본이 작다.** 직접 만든 문서 14개, 검색어 15개다. 실제 사업보고서 원문(긴 문장, 표, 숫자)에서 정밀도가 유지되는지는 모른다.
- **순위는 재지 않았다.** 찾았는지 여부만 봤고, 정답이 위쪽에 오는지는 보지 않았다.
- **한 글자 검색어는 안 된다.** 두 글자씩 자르기 때문이다 (예: `주`).
- **형태 변화와 동의어는 처리하지 않는다.** `선임했다`/`선임하였다`, `KB금융`/`KB금융지주`/`케이비금융지주`는 같은 말로 묶이지 않는다. 의미가 비슷한 문장 찾기는 벡터 검색에 맡기고, 회사명은 corp_code로 연결한다.
- **두 글자 조각이 겹치면 넓게 잡힌다.** `"이사"`는 `사외이사`, `대표이사`, `이사회`를 모두 찾는다. 이 실험에서는 정답 범위였지만 검색어가 짧을수록 정밀도가 떨어질 수 있다.

## 다른 방법이 나았을 조건

- **앱에서 형태소 분석 후 색인** (예: 한국어 형태소 분석기로 명사만 뽑아 `whitespace` 분석기로 색인): 실제 원문에서 `cjk` 구절 검색의 정밀도가 떨어지거나, 형태 변화 처리가 꼭 필요해질 때. 의존성(분석기 라이브러리)과 색인 속도가 비용이다.
- **전문검색을 별도 검색엔진으로 분리** (OpenSearch + nori 등): 전문검색이 이 프로젝트의 중심 기능이 되거나, Neo4j 안에서 품질을 맞출 수 없을 때. 저장소가 하나 늘고 동기화가 필요하다.
