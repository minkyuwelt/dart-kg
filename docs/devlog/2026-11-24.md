### 3번 PR 노트북 검증 (#30 병합) → 수정 PR fix/document-parse-lenient
- 사업보고서 백필 `--kind 11011`: 190건 중 187건 저장(125MB, 1.0분), 3건은 DART status 014 "파일이 존재하지 않습니다" — 모두 **[첨부정정]** (에이비엘생명보험·하나캐피탈 2025.12, 우리금융지주 2024.12). 첨부만 고친 정정은 본문 원문이 따로 없음
- 내장 파서만으로 `parse`: 파일 458개 중 **436개(95%) 실패**. 원인은 XML 규칙을 어긴 그대로의 `<`(`<P><당기말></P>` → mismatched tag)와 `&`(`S&P` → invalid token). DART 원문은 이름만 XML
- 대응 (`docs/decisions/0007-xml-parser.md`): 파서 3단계 — etree → 전처리(`&`→`&amp;`, 태그 아닌 `<`→`&lt;`)+etree → lxml recover. 전처리를 먼저 두는 이유는 `<당기말>` 글자 보존. 성공 단계를 `document_parse.parser`에 기록. `lxml==6.1.2` 추가
- 014는 `document.status='014'`로 기록해 다음 백필에서 건너뜀 (`save_missing_document`). 백필 출력에 "원문 없음" 수 표시
- 계획 결정 번호 이동: 청킹 0008, 임베딩 0009, LLM 0010
- 테스트 5개 추가 (총 106). **미검증**: 노트북에서 `parse` 재실행 후 단계별 건수 → 0007 "검증 결과"에 기록
